Password Security 101

A quick primer on why passwords get cracked, and what actually helps.

Length beats complexity

A 16-character passphrase composed of four random words is dramatically stronger than P@ssw0rd!. Every additional character multiplies the work an attacker must do.

Never reuse passwords

When a site you use is breached, attackers immediately try your email-and-password combo on every other popular service. A unique password per site contains the blast radius to one account.

Use a password manager

A modern password manager generates, stores, and autofills strong unique passwords so you don't have to remember them. The master password is the only one you actually need to know.

Turn on multi-factor authentication (MFA)

Even a strong password can leak. An authenticator-app or hardware key as a second factor blocks the vast majority of credential- stuffing attacks.

What this tool does (and doesn't)

  • Estimates entropy using Shannon's formula and pattern penalties.
  • Checks against a curated common-password list.
  • Detects sequential runs, keyboard rows, and 3+ repeated chars.
  • Stores only the SHA-256 hash, never the plaintext.
  • Does not check against real-world breach corpora (future feature).
